# Milestone Issue Plan

This document mirrors the intended GitHub issue order so implementation stays focused.

1. **Diagnostic core** — provider-independent session, evidence, hypotheses, state transitions, deterministic tests.
2. **Meta model adapter** — one eligible Meta inference route behind a validated adapter.
3. **Demo UI** — symptom input, evidence timeline, hypotheses, next test, result input, recommendation.
4. **Visual grounding** — SAM 3.1 or another eligible Meta visual capability if time/access permits.
5. **Demo hardening** — end-to-end rehearsal, validation log, README update, submission checklist.

Do not begin a later issue until the current milestone meets its acceptance criteria, unless a narrowly scoped prerequisite is required.
